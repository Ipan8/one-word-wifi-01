## The entry

**Gaslighting** — one word.

It says you are connected while giving you nothing. Full bars, zero internet. The router insists everything is fine; your video call insists otherwise. The most accurate word for Wi-Fi is the one that describes a relationship where one side keeps lying about the connection — and you keep believing it, because the signal bars say so.

## How to run

```sh
node main.ts
```

This writes the single entry word to `/output/entry.txt`.
